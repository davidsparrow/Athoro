# Authoro: notes for contributors and coding agents

Authoro is a public provenance registry for creative work. Read `Authoro-prd` for the product and `docs/decisions.md` for choices already made. Work proceeds in chunks tracked in `docs/roadmap.md`.

## Product rules the code must respect

- **Evidence, not verdicts.** Never write copy or code that says a work is "human-written", "AI-generated", "original" or "certified", and never compute a trust score. Describe concrete claims and who made them. Use the vocabulary in `packages/core/src/evidence.ts`.
- **Attribute every claim.** A third-party claim is "Reported by X". Anything the author supplies is labelled "Author supplied". Never present an unverified submission as an Authoro fact.
- **Humans finalize.** Agents and integrations may prepare a registration, but only the authenticated author can complete the attestation.
- **Nothing is silently rewritten.** Registered versions, attestation claims and event logs are immutable, and Postgres triggers enforce it (`apps/web/drizzle/0001_immutability.sql`). Corrections, revocations and withdrawals are new events or forward-only status changes.
- **Proof without surveillance.** Store hashes and aggregate evidence, not documents or raw telemetry. Documents are fingerprinted in the browser.
- **Public lookup stays free.** Resolving `/p/<id>` and verifying a document are never paywalled.

## Codebase

- pnpm monorepo. `packages/core` (Apache-2.0) must stay framework-free and isomorphic: Web Crypto, no Node APIs. `apps/web` (AGPL-3.0) is Next.js 16. Its APIs differ from older versions, so read `apps/web/AGENTS.md` and the bundled docs in `node_modules/next/dist/docs/` before writing Next code.
- Database: Drizzle ORM on Postgres with `casing: "snake_case"`, so schema keys are camelCase and columns snake_case. After editing `apps/web/src/db/schema.ts`, run `pnpm db:generate` and commit the SQL. Never hand-edit generated migrations. Write custom SQL with `drizzle-kit generate --custom`.
- Auth tables (`apps/web/src/db/auth-schema.ts`) are generated by the Better Auth CLI: `pnpm dlx auth@<better-auth version> generate --config src/lib/auth.ts --output src/db/auth-schema.ts`.
- Checks before pushing: `pnpm lint && pnpm typecheck && pnpm test && pnpm build`. Web integration tests need `TEST_DATABASE_URL`.
